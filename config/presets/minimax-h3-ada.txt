# MiniMax H3 for non-Blackwell cards (RTX 4090 / 4500 Ada, 24 GB).
#
# NVFP4 is a Blackwell-only format, so the 4-bit text encoder from the
# minimax-h3 preset will not run on Ada. This preset uses the int8 text
# encoder instead and the pruned int8 diffusion checkpoint, the combination
# the model ships with for 24 GB cards (int8 convrot + layerwise offload).
#
# Expect heavy offloading and slower generation than a 5090: the int8 text
# encoder alone is ~32 GB, so it will stream from system RAM. Give the pod
# plenty of RAM (>= 64 GB).
# Format: folder|filename|url[|sha256]
# size: ~55 GB

text_encoders|qwen3vl_32b_minimax_h3_int8.safetensors|https://huggingface.co/Comfy-Org/MiniMax-H3/resolve/main/text_encoders/qwen3vl_32b_minimax_h3_int8.safetensors
